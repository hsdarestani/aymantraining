## Fixes

- Correct suffix byte ranges for video/audio; reject invalid ranges with HTTP 416.
- Revoke bearer sessions on mobile logout.
- Enforce same-origin checks consistently; a mobile header without a bearer cannot bypass them.
- Filter FREE score detail responses and advanced wearable payloads.
- Apply saved step/water/protein targets to the native dashboard.
- Add native registration and password-reset entry point, with scrollable auth layout.
- Serialize offline queue updates; isolate pending data by account and pin synchronization to its originating bearer session.
- Show rejected set data and workout load/finish errors rather than marking validation failures as saved offline or spinning indefinitely.
- Correct literal backslash-newline text in four native screens.
- Normalize Android energy/weight objects to kcal/kg; use local dates and daily activity windows, explicit iOS units, and merge overlapping sleep intervals while excluding awake/in-bed stages. Sensor/device verification is still required.

## Limits requiring end-to-end device/service verification

No Android or iOS device/emulator is exposed in this environment. Native compilation/type checking and backend tests are not physical device tests. Actual FCM/APNs delivery, HealthKit/Health Connect authorization/import, store purchase/restore/renewal and Watch/widget behavior remain unverified here. Production PRO reads with an administrator are not an independent PRO-athlete acceptance test. CI uses a synthetic PRO trial for core paid workflows.

Real coach images/videos, operational coach content, final legal company details and provider integrations must be checked with their actual configured data. HTTP 200 does not establish content completeness. This report does not claim all PDF requirements or all native features are accepted.
